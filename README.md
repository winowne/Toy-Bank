# Toy Bank

Небольшой учебный консольный банк на Python. Приложение поддерживает вход по
PIN-коду, переводы, пополнение и снятие средств, смену PIN и просмотр истории.

## Запуск

Нужен Python 3.10 или новее. Дополнительные библиотеки не требуются.

```bash
python3 main.py
```

Приложение можно запускать из любой директории: файлы данных находятся рядом
с проектом, а не зависят от текущей директории терминала.

## Тестовые пользователи

| Пользователь | PIN | Баланс |
| --- | ---: | ---: |
| user | 1234 | 210 руб. |
| root | 1334 | 1790 руб. |
| павлов | 1235 | 0 руб. |

При первом запуске открытые PIN-коды автоматически заменяются хэшами в
`data/data.json`. После трех неверных попыток вход завершается.

## Возможности

- просмотр текущего баланса;
- переводы только положительных сумм в пределах доступного баланса;
- запрет перевода самому себе;
- пополнение и снятие средств с проверкой суммы и баланса;
- смена PIN-кода с проверкой старого PIN;
- история входящих и исходящих операций;
- безопасная атомарная запись JSON-файлов;
- обработка `Ctrl+C`, `Ctrl+D`, поврежденных данных и отмены операций через `0000`.

История хранится в `data/transfers.json`. Этот файл создается после первого
успешного перевода.

## Структура

- `main.py` — консольный интерфейс и навигация;
- `src/bank.py` — авторизация, переводы и история;
- `src/storage.py` — загрузка и атомарное сохранение JSON;
- `src/generator.py` — случайные приветствия и прощания;
- `data/` — учебные данные приложения.
